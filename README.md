# Welc'Home

Site web professionnel pour un service de menage et de conciergerie courte duree a Marseille et ses alentours.

## Stack

- Next.js
- TypeScript
- App Router
- SCSS Modules
- pnpm

## Commandes

```bash
pnpm install
pnpm dev
pnpm build
pnpm start
```

## Perimetre actuel

Cette premiere base contient uniquement :

- une structure Next.js propre ;
- une page d'accueil minimale ;
- un header simple ;
- une section hero simple ;
- un footer simple ;
- les styles en SCSS Modules.

Les elements suivants ne sont pas encore prevus dans cette etape :

- simulateur ;
- formulaire de contact ;
- dashboard ;
- backend ;
- API.
